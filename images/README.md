# images/ — נכסי מדיה לדף הנחיתה

עבור: `opsgen-landing-v2.html`

## מצב נוכחי
מוקאפי המוצר בדף (Hero + סקשן "המוצר") נבנו כ‑HTML/CSS לפי צילומי המסך של המערכת:
- מסך **בקרת ניהול AI** — מדדי סוכנים, עלות/הרצות, טבלת סטטוס סוכני AI
- מסך **טבלת חריגים** (מנוע חוקות AI) — טבלת נתונים עם סטטוס, אחוז חריג ופעולות

היתרון: הדף נשאר קובץ יחיד, המוקאפים רספונסיביים ותואמי מותג.

## להטמעת צילומי מסך אמיתיים במקום המוקאפים
לשמור כאן:
- `ai-control.png`        — צילום מסך "בקרת ניהול AI"
- `exceptions-table.png`  — צילום מסך "טבלת חריגים"

ואז להחליף ב‑`opsgen-landing-v2.html` את בלוק ה‑`<div class="appwin">` הרלוונטי ב‑
`<img src="images/ai-control.png" alt="בקרת ניהול AI" loading="lazy" />`
(מסומן בקוד בהערה `<!-- IMG SWAP -->`). כדאי לתת לתמונות רקע כהה עדין/מסגרת כדי שישבו על ה‑Hero.
