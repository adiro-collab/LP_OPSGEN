# OpsGen™ AI — Landing Page Build Brief for Claude

## 1. Goal

Build a high-conversion landing page for **OpsGen™ AI by SoluGen AI**.

The page will be used primarily for paid social / Facebook campaigns and should convert enterprise visitors into qualified leads by clearly explaining that OpsGen is **not just an AI agent that enters invoices into an ERP**, but an intelligent, proactive operational layer that understands business processes, validates information, detects exceptions, applies business rules, recommends actions, and can trigger the next step in the workflow.

### Primary conversion goal
Get the visitor to submit contact details so the SoluGen AI team can contact them and schedule a demo / discovery call.

### Primary CTA
**לתיאום הדגמה**

### Secondary CTA
**רוצה לראות איך זה עובד אצלכם? השאירו פרטים**

---

# 2. Language and Direction

- Primary language: **Hebrew**
- Direction: **RTL**
- Product and technical terms may stay in English when they are commonly used:
  - OpsGen™ AI
  - ERP
  - AI
  - GenAI
  - SAP
  - Oracle
  - Priority
  - Microsoft
  - 3-Way Match
- The tone should be clear, confident, innovative and enterprise-oriented.
- Avoid buzzword-heavy text.
- Avoid sounding like a generic “AI Agent” startup.
- Explain business value in language that CFOs, Procurement Managers, Operations Managers and CIOs immediately understand.

---

# 3. Brand & Design Source of Truth

The landing page must visually feel like a native continuation of the existing **SoluGen AI** website.

## Reference
Use the current SoluGen AI website and OpsGen pages as the design source of truth:
- Main SoluGen AI website
- OpsGen platform page
- Procurement Operations page
- Financial Operations page
- Document Processing page

## Critical design instruction
**Do not invent a new visual identity.**

Before implementing:
1. Inspect the existing SoluGen website/project.
2. Reuse the exact:
   - Header / navigation language
   - Logo assets
   - Fonts
   - Color variables
   - Gradients
   - Background treatments
   - Buttons
   - Border radii
   - Card styles
   - Shadows
   - Typography hierarchy
   - Spacing system
   - Footer
3. Reuse existing CSS variables, utility classes and components whenever possible.
4. If the source project is available locally, import existing assets rather than recreating them.
5. If a component already exists on solugen.ai, reuse or adapt it instead of creating a visually different version.

The final page should look like it belongs to the same website, not like an external campaign template.

# 5. Core Positioning

## Primary positioning statement

**OpsGen™ AI — ה-AI שלא מחכה שתשאלו אותו.**

OpsGen is a proactive AI layer for business operations.  
It understands what is happening across documents, ERP data and business workflows, detects what requires attention and helps drive the next action.

## Core differentiation

The visitor must understand this difference:

### Generic AI / basic automation
- Reads a document
- Extracts fields
- Enters data into ERP
- Answers when a user asks a question

### OpsGen
- Understands the business context
- Cross-checks multiple sources
- Applies business rules
- Validates data
- Detects exceptions
- Identifies operational risks
- Recommends actions
- Routes exceptions
- Triggers workflows
- Maintains traceability
- Works proactively rather than waiting for a prompt

## Brand line
**לא רק מבצע את התהליך. מבין אותו.**

Create an accordion with 5–6 questions.

OCR או Document AI מתמקדים בקריאת המידע. OpsGen ממשיך מעבר לכך — הוא מצליב את המידע מול מערכות ונתונים נוספים, מפעיל חוקים עסקיים, מזהה חריגות ומניע את המשך התהליך.

לא. OpsGen נועד לעבוד עם מערכות הליבה הקיימות ולהוסיף להן שכבת AI, בקרה ואוטומציה.

### עם אילו מערכות ניתן להתחבר?
הפתרון מיועד להשתלב בסביבות Enterprise ובמערכות ERP קיימות, כולל SAP, Oracle, Priority וסביבות Microsoft, בהתאם לארכיטקטורה ולממשקים הזמינים בארגון.

### האם אפשר להתחיל מתהליך אחד?
כן. נכון להתחיל מתהליך עסקי מוגדר, לחבר את מקורות המידע והחוקים הרלוונטיים, ולאחר מכן להרחיב לתהליכים נוספים.

### האם אפשר להגדיר חוקים ובקרות ייחודיים לארגון?
כן. OpsGen נועד לעבוד בהתאם לחוקים העסקיים, הוולידציות ותהליכי האישור של הארגון.

### האם המערכת רק מתריעה או גם יכולה לבצע פעולות?
בהתאם לתהליך ולהרשאות שהוגדרו, OpsGen יכול להציג המלצה, לנתב לטיפול, להפעיל Workflow או לבצע פעולה אוטומטית במערכות המחוברות.

# 18. Conversion UX Principles

The visitor should understand the page in under 10 seconds.

Above the fold must answer:
1. What is OpsGen?
2. Why is it different?
3. What business value does it create?
4. What should I do next?

## CTA rules
- Primary CTA must appear in the Hero.
- Repeat CTA after the main capabilities.
- Repeat CTA before / inside the final lead form.
- Use one primary action throughout: **לתיאום הדגמה**.
- Do not use many competing CTAs.
- All CTA buttons should scroll to the lead form or trigger the same demo flow.

# 19. Responsive Requirements

The page must be fully responsive.

Prioritize:
- 1440px desktop
- 1024px laptop/tablet
- 768px tablet
- 390px mobile

For Hebrew:
- Use RTL-aware spacing and alignment.
